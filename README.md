# Lumberjack Job

The Lumberjack Job is a FiveM resource that adds a realistic lumberjacking experience to your GTA5 server. Players can take on the role of a lumberjack, cutting down trees, collecting logs, and delivering them to a specified location. The resource includes map markers for tree locations, a minigame for cutting trees, a vehicle to carry logs, and a delivery system. It is designed to be integrated with essentialmode or es_extended for a seamless experience.

## Install

1. Download the resource from the GitHub repository.
2. Extract the files into your FiveM server's resources folder.
3. Add the following line to your server.cfg file: `ensure lumberjack_job`
4. Restart your FiveM server.

## Use

1. Players can start the lumberjack job by interacting with the job blip on the map.
2. Once the job is started, players will receive a vehicle to carry logs.
3. Players can cut down trees by interacting with them, which triggers a minigame.
4. After cutting down a tree, players can collect logs and load them into their vehicle.
5. Players need to deliver the logs to the specified delivery location.
6. After delivering the logs, players can return to the tree locations to cut down more trees.
7. The job continues until the player decides to quit or the server restarts.
